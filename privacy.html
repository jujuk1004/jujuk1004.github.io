hermes 개인정보처리방침

시행일: 2026년 10월 10일

1. 수집하는 정보

hermes는 사용자가 OAuth로 허용한 범위 안에서 다음 Google 데이터를 읽기 전용으로 조회합니다.

  • Google 캘린더: 당일 일정의 제목, 시간, 장소
  • Google Tasks: 완료되지 않은 할 일의 제목, 마감일, 메모
  • Gmail: 최근 1일간 받은 메일 중 긴급 키워드가 포함된 메일의 발신자, 제목, 요약

2. 이용 목적

조회한 정보는 사용자 본인에게 보내는 아침 브리핑을 만드는 데에만 사용합니다. 광고, 판매, 프로파일링 등 다른 목적으로 사용하지 않습니다.

3. 저장과 공유

  • 브리핑 결과와 인증 토큰은 사용자 본인의 PC에만 저장됩니다.
  • 브리핑은 사용자 본인의 Slack 채널로만 전송됩니다.
  • 어떠한 제3자에게도 데이터를 판매하거나 제공하지 않습니다.

4. Google API 서비스 사용자 데이터 정책 준수

hermes가 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

5. 권한 철회와 삭제

사용자는 언제든지 Google 계정 권한 페이지에서 hermes의 접근 권한을 철회할 수 있으며, PC에 저장된 토큰과 브리핑 파일을 삭제하면 모든 데이터가 제거됩니다.
